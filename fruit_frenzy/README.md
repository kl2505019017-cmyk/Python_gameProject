# Fruit Frenzy - Falling Objects Catch Game (SWC3643)

## Game concept
A 2D arcade game made with Python and Pygame. Fruits, a rare golden star, hearts and bombs fall
from the sky. Move the basket to catch the good items and dodge the bombs. Survive 60 seconds
to win. The game gets harder every 15 seconds (4 levels).

## Requirements and installation
```
python --version              # should show Python 3.14.x (3.10+ also works)
python -m pip install pygame
python -m pip install pillow  # only needed to re-create assets with generate_assets.py
```
If `pygame` has no wheel for your Python 3.14 yet, use the drop-in community edition instead
(same `import pygame` in code):
```
python -m pip install pygame-ce
```

## How to run
```
python main.py
```
Run it from inside the project folder (all paths are relative to the code, so any folder works).

## Controls
| Key | Action |
|---|---|
| Left / Right (or A / D) | Move basket |
| Up / Down + Enter | Menu navigation |
| P | Pause / resume |
| R | Restart (during play, pause or game over) |
| ESC | Back to main menu |
| L (menu) | Switch English / Bahasa Melayu |

## Game mechanics
| Item | Class | Result |
|---|---|---|
| Apple / Orange | `Apple`, `Orange` (`Fruit`) | +10 points; missed = -1 life |
| Banana | `Banana` (`Fruit`) | +15 points; missed = -1 life |
| Golden Star (rare) | `GoldenStar` | +30 points; missing it costs nothing |
| Heart (power-up) | `HeartPowerUp` | +1 life (max 5) |
| Bomb | `Bomb` | caught = -1 life; missing it is safe |

- Combo: every 5 fruits/items caught in a row raises the multiplier (x2, x3). Losing a life resets it.
- Win: timer reaches 0 with lives left. Lose: lives reach 0.
- Difficulty (`level.py`): every 15 s items spawn faster, start falling faster and more bombs appear.
- Physics: velocity increases every frame by `GRAVITY`; the player eases towards its target speed.
- Collision: `pygame.Rect.colliderect` between the item and the basket opening (`Player.catch_rect`).
- Items that leave the screen are removed with `kill()` so memory does not grow.


## OOP classes
- `Game` - owns everything; runs the loop (events -> update -> draw) and the states MENU, INSTRUCTIONS, PLAYING, PAUSED, GAME_OVER.
- `Player` - basket movement, boundaries, catch area.
- `Item` (base) with subclasses - each overrides `on_caught()` / `on_missed()` (polymorphism, inheritance).
- `Level` - spawn speed, fall speed and item probabilities for one level.
- `AssetManager` - loads/caches images and sounds, falls back safely.
- `FloatingText` - "+10" / "-1" effects. `Translator` - bilingual text.

## Assets
Images are 64x64 PNG (basket 120x70, background 800x600). Sounds are short WAV files.
All were generated by `generate_assets.py`; you can replace any file with your own using the same name.
If an image is missing the game draws a shape instead; if a sound is missing (or no audio device), it stays silent. It never crashes.
